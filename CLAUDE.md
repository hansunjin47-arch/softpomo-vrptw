# Repository Instructions

Read and follow [AGENTS.md](AGENTS.md) and [README.md](README.md) before running or
editing experiments. AGENTS.md is the single source of agent workflow rules;
README.md provides installation commands, method details, and troubleshooting.

Use the supported root entry points, existing offline caches, explicit Python
environment, and unique run directories. Do not enable API calls or change
experiment settings to bypass errors. Verify status and outputs before reporting
that training or evaluation has completed.
