This directory preserves the local experiment source layout without modifying
the repository's portable sequential entry points. It is a source/results review
snapshot, not a standalone training distribution. Original data, frozen source
bundles, credentials, checkpoints and paid confidence caches are not included.
Run imports relative to this directory when supplying those original artifacts.

- Concurrent fleet v9 environment/policy and Kim/Phase2 training pipelines.
- Test confidence output uses required customer-ID keys; cluster IDs are restored

  Its model selects the forced first customer next, charging the first arc.
